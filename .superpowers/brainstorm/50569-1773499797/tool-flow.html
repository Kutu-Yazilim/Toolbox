Component Architecture

How components nest inside the PDF tab

Component Tree
App.tsx
└─ TabsContent value="pdf"
└─ PdfTools.tsx ── manages activeTool state
├─ PdfToolsHub.tsx ── when no tool selected
│ ├─ "Convert to PDF" section (8 tool cards)
│ └─ "Manage PDF" section (5 tool cards)
└─ PdfToolLayout.tsx ── when tool selected (back btn + title)
└─ <ActiveTool /> ── e.g. PdfMerge, CsvToPdf
├─ PdfFileDropZone ── shared upload
├─ [tool config UI] ── tool-specific options
├─ PdfProgressBar ── processing feedback
├─ PdfPreviewPanel ── result preview
└─ PdfDownloadButton ── download action
